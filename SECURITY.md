# Security

Version 0.1.x is the current supported line. Do not publish sensitive inputs,
database files, credentials, or personal data in issues.

Report suspected vulnerabilities privately using
[GitHub private vulnerability reporting](https://github.com/KanadeK/csv-relguard/security/advisories/new).
If that form is unavailable, contact the maintainer through the
[GitHub profile](https://github.com/KanadeK) to arrange a private channel; disclose
no vulnerability details in the initial public contact. No response SLA is promised.

This is a local diagnostic tool, not a sandbox or a guarantee that inputs are safe.
Use maintained Python/SQLite releases and OS resource limits for hostile inputs.
